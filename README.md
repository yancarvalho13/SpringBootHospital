
# Spring Boot Hospital Management System

Este projeto é uma API RESTful para gerenciar um sistema de hospital, desenvolvido com Spring Boot e integrações com MySQL/MariaDB.

## Tecnologias Utilizadas

- **Spring Boot**: Framework Java para construção de APIs.
- **JPA e Hibernate**: Mapeamento objeto-relacional.
- **MySQL/MariaDB**: Banco de dados relacional.
- **Spring Data JPA**: Gerenciamento de persistência.
- **Flyway**: Migrações de banco de dados.
- **Swagger**: Documentação de API.
- **Lombok**: Redução de código boilerplate.

## Funcionalidades

- Gerenciamento de pacientes, médicos e consultas.
- Operações CRUD.

## Como Executar

1. Clone o repositório.
2. Configure o banco de dados no `application.properties`.
3. Execute com `mvn spring-boot:run`.
